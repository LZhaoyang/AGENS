# AGENS
 
This repository is an official codebase accompanying the paper **"Agentic Link Construction for Environment and Intent Aware 6G Communication"**, with an emphasis on reproducibility and extensibility.

At the current public release stage, we provide the most essential and independently reusable components of the framework:
- **Dataset generation pipeline** for environment- and intent-aware communication tasks;
- **Communication link construction and simulation modules** for link-level modeling, signal processing, and simulation studies.

This staged release is intended to support early replication of the core experimental setup and to facilitate follow-up research built on top of these modules.
